Weekly summary — ready to paste into Slack, a 1:1 doc, or email.

Connect to Google Sheets in five steps. Wins are sent via a GET request — no CORS issues, no tokens needed.

一
Create a Google Sheet
Go to sheets.google.com → New blank spreadsheet. Name it "Work Wins". In row 1, add headers: Date, Win, Category, Impact, Synced
二
Open Apps Script
Inside your sheet: Extensions → Apps Script. Delete any existing code and paste this:
function doGet(e) { const ss = SpreadsheetApp.getActiveSpreadsheet(); const sh = ss.getActiveSheet(); const p = e.parameter; sh.appendRow([ p.date || new Date().toISOString(), p.win || '', p.cat || '', p.impact || '', 'Synced' ]); return ContentService .createTextOutput(JSON.stringify({ status: 'ok' })) .setMimeType(ContentService.MimeType.JSON); }
三
Deploy as Web App
Click Deploy → New deployment. Type: Web App. Execute as: Me. Who has access: Anyone. Click Deploy → copy the Web App URL.
四
Paste your Web App URL
五
Sync your wins
Return to the Wins tab and click Sync to Sheets. Each pending win opens a brief tab, appends a row, and closes automatically.
Tips
· Always create Apps Script from inside the Sheet via Extensions → Apps Script, not from script.google.com directly.
· If sync tabs open but nothing appears in the sheet, redeploy the script (Deploy → Manage deployments → Edit → new version).
· localStorage key is workwins_v3 — don't change it or you'll lose saved wins.
· Sync regularly — localStorage clears when the browser cache is cleared.
